    In OBS add a Browser Source with the first URL and it follows whichever preset is active; switch from here, the tray icon, or a Stream Deck button (below). Changes you make here apply to running sources immediately.

    Stream Deck / hotkey control

    Switch presets and turn the gyro displays on or off from a Stream Deck button, a hotkey tool or a script: each is a plain web address that does the job when it is opened (an HTTP GET).

    OBS Browser Source size

    Type the width and height into your Browser Source's properties, then move and resize the source with OBS's handles as usual. The overlay is pinned inside the source by the Position setting below, so switching presets never shifts it. A tight size gives a tight red box in OBS; a bigger source (e.g. 1920×1080) lets you pin to a corner. To make it bigger, use the Size slider here rather than stretching the source in OBS, which blurs it. The preview below is drawn at this size; the dashed line is the source's edge.

    Preview

    Background
    The preview reacts to your real input. Drag the right edge of a key to resize it (the rest of the overlay moves to fit); double-click an edge to reset that key.

    Keyboard

    Click a key to hide or show it. Click and drag to paint several.
    Settings apply to the selected preset, except the ones tagged all presets. Click a tag to switch that setting between all presets and just this preset.

    Mouse

    Swaps which side button is drawn as Mouse 4 and Mouse 5.

    Controller

    For controllers with motion sensors (Steam, PlayStation, Switch). Tilt leans the controller picture as you turn it; Aim adds a box with a dot that follows the turn and leaves a trail. Only shown where the controller is. The Stream Deck gyro buttons switch this to all presets.

    Stream Deck / hotkey URLs

    Each one is a plain GET request. In Stream Deck use the built-in Website action with "Access in background" ticked (or an API plugin such as BarRaider's API Ninja). The gyro ones switch the gyro displays on or off for every preset (they set Gyro to "all presets"); the aim dot and tilt only show where the controller is shown.
